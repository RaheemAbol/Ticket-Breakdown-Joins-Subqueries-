# Real Estate Database — TB_12
## Practice Project: Subqueries and Joins

- Set up the database using the provided `RealEstateDB` SQL script.
- Confirm that all tables and sample data were created successfully.
- Complete each question using SQL.
- Use a subquery or join as requested.

## Ticket Breakdown

### 1. Properties More Expensive Than `123 Main St`

Find the address, city, and listing price of every property that is more expensive than the property at `123 Main St`.

- Use a subquery to find the listing price of `123 Main St`.

### 2. Properties and Their Property Types

List each property address, city, and property type name.

- Use a join between `Properties` and `PropertyTypes`.

### 3. Agents Who Listed Properties in California

Find the first and last names of agents who have listed at least one property in California.

- Use a subquery to identify the matching `AgentID` values.
- Do not display duplicate agents.

### 4. Property Details

Display each property address, number of bedrooms, and number of bathrooms.

- Join `Properties` with `PropertyDetails`.

### 5. Properties Below AgentID 2's Average Listing Price

Find the addresses and listing prices of properties that cost less than the average listing price of all properties listed by AgentID 2.

- Use a subquery to calculate AgentID 2's average listing price.

### 6. Completed Sales

List the client's first name, client's last name, property address, and sale price for completed sales.

- Join `Clients`, `Transactions`, and `Properties`.
- A completed sale is represented by the status name `'Sold'` in `PropertyStatus`.

### 7. Properties With the Same Bedroom Count as `789 Oak St`

Find the addresses and bedroom counts of all properties that have the same number of bedrooms as `789 Oak St`.

- Use a subquery to find the bedroom count for `789 Oak St`.

### 8. Every Agent and Their Listed Properties

Display every agent's first name, last name, and the address of each property they listed.

- Use a `LEFT JOIN` between `Agents` and `Properties`.
- Include agents who have not listed a property.

### 9. Clients With Below-Average Completed Purchases

Find the first and last names of clients who purchased a property for less than the average sale price of all completed sales.

- Use a subquery to calculate the average `SalePrice` for completed sales.
- Join the results with `Clients`.
- Do not include transactions with a `NULL` sale price.

### 10. Properties and Their Amenities

List each property address and the name of each amenity assigned to it.

- Join `Properties`, `PropertyAmenityAssignments`, and `PropertyAmenities`.
- A property with multiple amenities may appear on multiple rows.
